## プロジェクト概要

■ 概要

本プロジェクトは、VR向けのプラネタリウムアプリケーションとして開発した。
特に「没入感の向上」と「非同期処理を用いたスムーズな演出」の設計に重点を置いている。

■ 設計（コア部分）

・非同期処理の実装（最重要）

演出の制御にUniTaskを採用。
フェードイン・フェードアウトなどの時間経過を伴う処理を非同期化し、コードの可読性を高めつつスムーズなシーン遷移を実現した。

・オーディオ制御システム

プレイヤーの水平方向（Y軸）の向きに応じて音量が変化する特殊なオーディオ処理を実装。
単純な距離減衰ではなく、VR空間ならではの音響体験を構築した。

■ 実装（システム）

・VR向け視点制御

VR環境での鑑賞を前提としたカメラの向きや視点の初期化処理を実装。

・デバッグ機能

開発効率向上のため、キー入力によるデバッグ操作系を実装し、動作確認を容易にした。

■ 演出・体験設計

・視覚効果

星座やキャラクター画像の配置、および描画順序を細かく調整し、プラネタリウムとしての美しさを表現。

・サウンド体験

BGM・SEを適切に配置し、視覚だけでなく聴覚からも没入感を高める設計とした。

■ 工夫・改善点

・UniTaskの導入により、複雑になりがちな演出系のコルーチン処理をシンプルに記述可能にした

・音声の特殊制御により、VR空間におけるプレイヤーの「向き」を意識させる体験を作り出した

・プロジェクト全体のフォルダ・スクリプト構成を整理し、保守性を向上させた

## 開発メンバーと担当箇所

本プロジェクトは個人開発です。
* プロジェクト立ち上げと基本設計(Unityプロジェクト構成、フォルダ・スクリプトの整理)
* 視覚効果と画像制御(星座やキャラクター画像の配置、描画順序の調整)
* 演出機能の実装(UniTaskを用いたフェードイン・フェードアウト処理の実装)
* オーディオ制御(BGM・SEの追加、プレイヤーの水平方向(Y軸)の向きに応じた音量変化の特殊処理の実装)
* カメラと入力処理(VR向けカメラの向き調整、デバッグ用キー入力の実装)
